Project Overview

DASI Web Dashboard adalah platform backend berbasis Laravel yang dirancang untuk mengelola seluruh proses bisnis penjualan modem secara terpusat. Sistem ini mengintegrasikan manajemen stok, monitoring pergerakan barang (Stock Movement), proses retur, laporan penjualan, serta AI Assistant yang membantu pengguna memperoleh informasi bisnis dengan lebih cepat. Dashboard analitik yang interaktif memberikan visibilitas menyeluruh terhadap operasional perusahaan sehingga pengambilan keputusan dapat dilakukan secara real-time.

Key Features

Inventory & Stock Management

Mengelola stok produk secara terpusat dengan monitoring ketersediaan barang, mutasi stok, dan histori pergerakan inventori secara lengkap.

Sales & Return Management

Mendukung proses transaksi penjualan, retur barang, serta validasi data untuk memastikan setiap transaksi tercatat dengan akurat.

AI Business Assistant

Terintegrasi dengan AI Chat yang membantu pengguna mencari data, menjawab pertanyaan operasional, dan mempercepat analisis bisnis.

Interactive Dashboard & Reports

Dashboard analitik dengan berbagai laporan penjualan, stok, dan performa bisnis yang diperbarui secara real-time.

Challenges & Solutions

Konsistensi Stok Multi-channel

Tantangan: Penjualan dilakukan serentak oleh sales lapangan via mobile app dan admin via web dashboard. Tanpa penanganan khusus, penambahan atau pengurangan stok bersamaan berisiko menimbulkan selisih data stok (race conditions).

Solusi: Menggunakan database transactions Laravel dengan tingkat isolasi serializable dan locking mechanism (SELECT FOR UPDATE) saat mutasi stok terjadi.

Asisten AI Interaktif

Tantangan: Pengguna non-teknis kesulitan untuk mengekstrak insight tren penjualan jika harus melihat tabel yang kompleks.

Solusi: Membangun integrasi AI chatbot yang terhubung langsung ke database via API terenkripsi. AI dibekali system prompt khusus untuk membaca query database ter-aggregasi dengan aman tanpa mengekspos data kredensial.
